# 🛒 Grocery Store Website

This is a simple frontend grocery store website created as a project for my **Social Internship**. It provides a clean and user-friendly interface where users can browse grocery products and categories.

## Technologies Used

* HTML
* CSS
* JavaScript

## Features

* Clean and simple design
* Grocery product listings
* Product categories
* Responsive layout
* Interactive elements

## Purpose

This project was created as part of my **Social Internship** to practice frontend web development skills and create a basic online platform for a local grocery store.
